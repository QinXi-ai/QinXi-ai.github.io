## Open-source work

Each featured pull request was checked through GitHub's API for its public visibility, author (`QinXi-ai`), merged state, merge date, and diff statistics. Descriptions and validation summaries come from the linked PRs. Test counts describe the contribution's recorded validation, not tests rerun for this website update.

- [Apache DataFusion #25150](https://github.com/apache/datafusion/pull/25150): supported fully ordered multi-column aggregation without hashing. No general query-speedup claim is made.
- [Xarray #11552](https://github.com/pydata/xarray/pull/11552): DataTree dispatch in `apply_ufunc`.
- [AWS Labs Stickler #284](https://github.com/awslabs/stickler/pull/284): NumPy metric implementations and removal of the core scikit-learn dependency.
- [SysKnife #514](https://github.com/lacs-project/sysknife/pull/514): credential-taking actions excluded from the natural-language planner.
- [dataprof #655](https://github.com/AndreaBozzo/dataprof/pull/655): column projection across Rust, Python, and physical Parquet reads.
- [Manim #2501](https://github.com/3b1b/manim/pull/2501): batched 2D rotation and VectorField reproduction.

Project descriptions were checked against their current public READMEs. AstroTwin is labeled as a public demo; its private research repository is not presented as open source. The smart-home project uses simulated devices. MoonCat's separate hardware-developer submission is not used as proof of the CCF smart-band award.
